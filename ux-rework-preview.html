UX Rework Plan

Phased migration from kazma.css v4 → DS v5 “Aurora”. Zero backend changes.

1Design tokens & foundation

Introduce a semantic token layer on top of today's raw palette. Everything maps onto existing CSS variables, so old templates keep rendering while pages migrate one-by-one.

TokenDarkLightUsed for
--bg-0#05080d#eef1f6app canvas
--bg-2#0e141d#ffffffcards
--accent#22d3ee#0891b2primary actions (kept brand cyan)
--accent-2#8b5cf6#7c3aedNEW — AI / swarm identity
--gradcyan → indigo → violetbrand moments, active states
  • Semantic aliases: surface/card/elevated, text-1/2/3, line/line-strong — replaces 40+ ad-hoc rgba() literals.
  • Light theme becomes a pure token swap on [data-theme="light"] (today: dark-only).
  • Type scale fixed to 8 steps (11.5 → 32px), tabular numerals for all metrics.

2Responsive architecture (every device)

  • Breakpoints: ≥1100px full sidebar · 768–1100px icon rail · ≤768px off-canvas drawer + bottom tab bar · ≤520px compact density.
  • Container queries for components (cards, chat composer) so embeds/panels respond to their own width, not just the viewport.
  • All inline 2-col grids → .two-col-grid (already collapses ≤768px); audit and replace stragglers.
  • Bottom tab bar gains the 4 core destinations + “More” drawer; desktop keeps ⌘1–4 shortcuts.
  • Touch targets ≥ 36px, hover states get pointer: fine media guards.
  • RTL verified at every breakpoint (this preview has a live RTL toggle — try it).

3Navigation & shell

  • Sidebar regrouped: Primary / Workspace / System (3 groups instead of 4) with active-rail indicator.
  • Topbar: breadcrumb + ⌘K command palette + live system status pill + notifications.
  • Model selector moves into a persistent footer pill (visible on every screen, shows provider).

4Page-by-page uplift

  • Dashboard: greeting hero, 4 stat cards with deltas, throughput chart, platform health, quick actions.
  • Chat: session rail, tool-call chips with live status, focused composer glow, model chip inline.
  • Swarm: worker cards (status/success/model), queue rows with progress bars.
  • Settings: section-nav + rows pattern; toggles replace checkboxes.

5Migration strategy (safe rollout)

  • New file kazma.v5.css loaded after kazma.css — pages opt in via a body class; rollback = remove one link tag.
  • Migrate in order: tokens → shell (sidebar/topbar) → dashboard → chat → swarm → settings → long tail.
  • Each phase is one PR with before/after screenshots at 4 widths (1380/1024/820/390).
  • Respect existing conventions: x-cloak global rule, kazmaConfirm/kazmaAlert dialogs, single toast system, two-col-grid.
